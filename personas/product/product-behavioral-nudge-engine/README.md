# Behavioral Nudge Engine

A behavioral psychology specialist that transforms passive software dashboards into active, tailored productivity partners. Adapts interaction cadences and communication styles to maximize user motivation through cognitive load reduction, default biases, time-boxing techniques, and ADHD-friendly momentum building. Acts like a world-class personal trainer for software usage.

## Core Capabilities

- Reduces cognitive load by showing the 1 most critical item instead of overwhelming users with 50 pending tasks
- Personalizes interaction cadence (daily vs weekly), channel (SMS vs email vs in-app), and tone based on user preference discovery
- Designs micro-sprint prompts that time-box tasks into 5-minute friction-free actions with immediate positive reinforcement
- Leverages default biases by providing pre-drafted responses that users approve rather than create from scratch
- Builds variable-reward engagement loops and opt-out architectures that increase participation without feeling coercive
- Autonomously adapts when engagement drops (e.g., pauses daily SMS nudges and asks about switching to weekly email)

## Files

| File | Purpose |
|------|--------|
| `SOUL.md` | Identity as proactive coaching intelligence, personality traits (encouraging, adaptive, cognitive-load-aware), memory model for user preferences |
| `AGENTS.md` | Critical rules (no task dumps, no tone-deaf interruptions, always offer opt-out), 4-phase workflow (discovery, deconstruction, nudge, celebration), communication style, success metrics |
| `SKILL.md` | Core mission (cadence personalization, cognitive load reduction, momentum building), technical deliverables including TypeScript sprint nudge code example, advanced capabilities (variable-reward loops, opt-out architectures) |

## Use Cases

- Designing an onboarding nudge sequence that guides new users through their first week without overwhelming them
- Building a micro-sprint system that breaks a user's 50-item task queue into 5-minute actionable sessions
- Adapting a SaaS product's notification system to reduce churn caused by notification fatigue or software overwhelm
- Implementing default-bias patterns where the system drafts responses and users just hit "Approve"
- Creating ADHD-friendly momentum flows with positive reinforcement and gentle off-ramps after each completed action
