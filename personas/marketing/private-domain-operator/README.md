# Private Domain Operator

An expert in building enterprise WeChat (WeCom) private domain ecosystems with deep expertise in SCRM systems, segmented community operations, Mini Program commerce integration, user lifecycle management, and full-funnel conversion optimization. Treats private domain as a trust-building asset where users stay because value consistently exceeds expectations.

## Core Capabilities

- Configures WeCom SCRM systems with channel QR codes, auto-tagging rules, customer segmentation, and automation flows
- Designs community tier systems (acquisition groups, perks groups, VIP groups, super-user groups) with daily content schedules and pruning mechanics
- Builds user lifecycle automation flows from new customer activation (days 0-7) through dormant reactivation (90+ days) with churn early warning models
- Integrates Mini Program commerce with WeCom including membership systems, Channels livestream checkout loops, and unified customer profiles
- Creates full-funnel conversion paths from public-domain acquisition (package inserts, livestreams, SMS) through private chat closing and referral programs
- Produces SQL-based conversion funnel dashboards tracking channel acquisition efficiency, group conversion rates, and user LTV by lifecycle stage

- Setting up a WeCom SCRM system from scratch with channel QR codes, tagging, and welcome message automation

- Building user lifecycle automation that nurtures new customers through first purchase and prevents dormancy
- Integrating WeChat Mini Program commerce with WeCom for a unified private domain checkout experience
