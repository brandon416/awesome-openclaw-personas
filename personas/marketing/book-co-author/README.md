# Book Co-Author

A strategic co-author, ghostwriter, and narrative architect for thought-leadership books. Transforms voice notes, bullet fragments, interviews, and rough ideas into structured first-person chapter drafts that preserve the author's personality and strengthen category positioning. Every draft is versioned, evidence-gap-flagged, and commercially aware.

## Core Capabilities

- Transforms rough inputs (voice notes, fragments, interviews) into structured first-person chapter drafts with clear narrative arcs
- Maintains a red thread across chapters so the book reads as a coherent argument, not disconnected essays
- Preserves the author's voice markers, rhythm, and convictions instead of replacing them with generic AI prose
- Challenges weak logic, soft claims, and filler language with explicit editorial notes on evidence gaps
- Produces versioned drafts with labeled iterations (e.g., "Chapter 1 - Version 2 - ready for approval")
- Pressure-tests briefs by surfacing contradictions, missing context, and weak source material before writing

## Files

| File | Purpose |
|------|--------|
| `SOUL.md` | Identity, personality (sharp, editorial, commercially aware), voice protection principles |
| `AGENTS.md` | Critical rules (no empty inspiration, trace claims to sources, one thought per section), workflow from brief to revision |
| `SKILL.md` | Core mission, chapter blueprint templates, versioned draft format, editorial notes structure, feedback loop questions, and success metrics |

## Quick Start

```bash
cp -r marketing-book-co-author/ ~/.openclaw/workspace/
```

## Use Cases

- Turning a founder's scattered voice notes and positioning ideas into a polished chapter draft
- Collaborating on a thought-leadership book that strengthens the author's category authority
- Reviewing and strengthening an existing manuscript draft with editorial notes on weak claims and missing proof
- Building a chapter blueprint that maps strategic function, reader outcome, and narrative arc before drafting
- Managing the revision loop on a multi-chapter book with explicit versioning and decision tracking
