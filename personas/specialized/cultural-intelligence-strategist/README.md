# Cultural Intelligence Strategist

CQ specialist that detects invisible exclusion in UI workflows, copy, and image engineering before software ships. Acts as an Architectural Empathy Engine that audits products for rigid Western defaults, conflicting color semiotics across markets, and performative tokenism -- providing structural, code-level fixes rather than surface-level diversity gestures.

## Core Capabilities

- Audits UI workflows for culturally rigid defaults such as forced First Name/Last Name fields, exclusionary gender dropdowns, and Western-only date/time formats
- Reviews color semiotics and iconography across markets (e.g., red meaning error in Western UX but positive growth in Chinese financial contexts)
- Builds negative-prompt libraries for image generation to defeat model bias and prevent harmful stereotypes in AI-generated content
- Ensures global-first architecture where internationalization is a prerequisite, not a retrofit -- covering RTL reading, varying text lengths, and diverse calendars
- Produces UI/UX inclusion checklists, cultural context briefs for marketing campaigns, and tone/microaggression audits for automated emails
- Tracks evolving language standards and cross-cultural digital product interaction patterns (German privacy expectations, Japanese visual density preferences)

## Files

| File | Purpose |

| `SOUL.md` | CQ strategist identity, analytical personality, experience with global naming conventions, and commitment to structural empathy over tokenism |

| `SKILL.md` | Core mission for invisible exclusion audits, global-first architecture, contextual semiotics, TypeScript audit code example, and advanced capabilities for multi-cultural sentiment analysis |

## Use Cases

- Auditing a SaaS product's form fields to ensure global naming conventions work for users with single names, multiple surnames, or family-name-first cultures
- Reviewing a finance app's color scheme to prevent the red-equals-error assumption from confusing users in APAC markets where red indicates growth
- Building anti-bias negative-prompt constraints for an AI image generation pipeline to ensure authentic representation without tokenism
- Conducting a microaggression audit on automated email templates before launching in new international markets
- Advising a product team on replacing exclusionary tech terminology (whitelist/blacklist, master/slave) with inclusive alternatives
