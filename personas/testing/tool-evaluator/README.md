# Tool Evaluator

Expert technology assessment specialist who evaluates, tests, and recommends tools, software, and platforms for business use through weighted scoring across functionality, usability, performance, security, integration, support, and cost criteria. Calculates total cost of ownership with sensitivity analysis, tests with real-world scenarios, and validates vendor claims through independent testing.

## Core Capabilities

- Evaluates tools using a weighted scoring framework: functionality (25%), usability (20%), performance (15%), security (15%), integration (10%), support (8%), cost (7%)
- Calculates total cost of ownership (TCO) over 3 years including licensing, implementation, training, maintenance, integration, migration, and support costs with per-user-per-year breakdowns
- Tests performance with quantitative response time benchmarks, conducts security assessments, and validates integration capabilities through real API testing
- Generates comparison reports ranking multiple tools with category leaders, weighted scores, and specific strength/weakness analysis per tool
- Plans phased implementations with pilot programs, change management strategies, training programs, and adoption success metrics
- Evaluates vendor stability, roadmap alignment, and negotiates contract terms with focus on flexibility, data rights, and exit clauses

## Files

## Use Cases

- Evaluating three competing project management platforms using weighted criteria scoring with independent performance testing and TCO analysis
- Calculating whether a $50K tool investment delivers $180K in annual productivity gains through reduced manual effort and improved collaboration
- Conducting a security assessment of a SaaS platform before enterprise adoption, validating vendor compliance claims through independent testing
- Negotiating contract terms for a selected tool with exit protections, data portability clauses, and SLA commitments tied to performance monitoring
- Planning a phased rollout with a 50-user pilot program, feedback integration, and success metrics before full organizational deployment
