# Test Results Analyzer

Expert test analysis specialist who transforms raw test data into strategic quality insights using statistical methods, predictive modeling, and ROI analysis. Aggregates results from unit, integration, performance, and security testing to identify failure patterns, assess release readiness with confidence intervals, predict defect-prone areas with machine learning, and deliver actionable recommendations to both technical teams and executive stakeholders.

## Core Capabilities

- Analyzes test results across functional, performance, security, and integration testing with statistical pattern recognition and anomaly detection
- Calculates release readiness with quantitative risk assessment, go/no-go recommendations backed by confidence intervals and statistical significance testing
- Predicts defect-prone areas using Random Forest classifiers trained on historical defect data and code metrics with feature importance rankings
- Performs failure pattern analysis with root cause categorization (functional, performance, security, integration) and trend identification over time
- Produces stakeholder-specific reports: executive dashboards with quality scores and business impact, technical reports with coverage gaps and defect density per KLOC
- Tracks quality debt and provides ROI analysis for quality improvement investments with projected cost savings from early defect detection

## Files

| File | Purpose |
|------|---------|
| `SOUL.md` | Test results analyzer identity, analytical personality, experience with data-driven quality decisions vs. gut-feeling failures |
| `AGENTS.md` | Data-driven analysis rules (statistical validation required, confidence intervals mandatory), quality-first decision making principles, four-step workflow, and success metrics |
| `SKILL.md` | Python TestResultsAnalyzer class with coverage analysis, failure pattern identification, defect prediction (Random Forest), release readiness assessment, and executive report generation; deliverable report template; advanced capabilities for ML, NLP-based defect classification, and quality maturity assessment |

## Quick Start

```bash
cp -r testing-test-results-analyzer/ ~/.openclaw/workspace/
```

## Use Cases

- Analyzing 50,000 test results to identify that 73% of defects originate from the integration layer, with statistical confidence and root cause categorization
- Producing a go/no-go release recommendation backed by test pass rates, coverage thresholds, performance SLA validation, and defect density calculations
- Training a defect prediction model on historical data to flag high-risk code areas before they accumulate bugs in production
- Creating an executive quality dashboard showing overall quality score, trend direction, top 3 risks with probability/impact, and recommended investments
- Quantifying quality debt: "Quality investment of $50K prevents estimated $300K in production defect costs based on historical escape rates"
