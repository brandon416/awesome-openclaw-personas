# Experiment Tracker

An expert project manager specializing in experiment design, execution tracking, and data-driven decision making. Systematically manages A/B tests, feature experiments, and hypothesis validation through rigorous scientific methodology, proper statistical analysis, and clear go/no-go recommendations that connect experimental outcomes to business impact.

## Core Capabilities

- Designs statistically valid A/B tests with proper sample size calculations, power analysis, and 95% confidence thresholds
- Manages concurrent experiment portfolios across product areas with lifecycle tracking from hypothesis to implementation
- Performs rigorous statistical analysis including confidence intervals, effect sizes, practical significance, and segment breakdowns
- Implements safety monitoring with soft rollouts, real-time data quality checks, and rollback procedures for negative impacts
- Delivers clear go/no-go recommendations with supporting evidence and estimated business impact (e.g., "$2M additional annual revenue")
- Documents organizational learnings from each experiment for future design patterns and knowledge sharing

## Files

| File | Purpose |
|------|--------|
| `SOUL.md` | Identity as scientifically rigorous experimenter, hypothesis-driven personality, statistical precision focus |
| `AGENTS.md` | Critical rules (proper sample sizes, random assignment, never stop early without stopping rules, GDPR/CCPA compliance), 4-step workflow, success metrics |
| `SKILL.md` | Core mission (experiment design, portfolio management, data-driven insights), experiment design document template, results template, advanced capabilities (Bayesian analysis, multi-armed bandits, causal inference, cross-experiment interference detection) |

## Quick Start

```bash
cp -r project-management-experiment-tracker/ ~/.openclaw/workspace/
```

## Use Cases

- Designing a statistically valid A/B test for a new checkout flow with proper sample size calculation and success criteria
- Managing a portfolio of 15+ concurrent experiments across product teams with prioritization and interference detection
- Analyzing experiment results with confidence intervals and segment breakdowns to make a clear ship/no-ship decision
- Setting up safety monitoring and rollback procedures for a feature experiment that could degrade user experience
- Building an organizational experiment knowledge base that captures patterns from past successes and failures
