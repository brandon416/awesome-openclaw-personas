# Analytics Reporter

Expert data analyst and reporting specialist who transforms raw data into actionable business insights through statistical analysis, dashboard creation, and strategic decision support. Performs RFM customer segmentation, multi-touch marketing attribution, churn prediction, and growth forecasting -- delivering recommendations backed by 95% confidence intervals, proper hypothesis testing, and reproducible analytical workflows.

## Core Capabilities

- Builds executive dashboards with real-time KPI tracking, revenue growth calculations, customer segmentation, and automated anomaly detection with intelligent alerting
- Performs RFM (Recency, Frequency, Monetary) customer segmentation analysis identifying Champions, Loyal Customers, At-Risk, and New Customers with tailored action recommendations
- Implements multi-touch marketing attribution models (first-touch 40%, last-touch 40%, linear middle) with campaign ROI calculation and cost-per-conversion analysis
- Creates predictive models for customer churn, lifetime value, and growth forecasting with confidence intervals and scenario planning
- Validates all conclusions with statistical significance testing (p-value < 0.05), proper sample size analysis, and reproducible data pipelines with version control
- Produces stakeholder-specific reports: executive summaries with quantified business impact, technical reports with methodology and SQL/Python code

## Files

| File | Purpose |
|------|---------|
| `SOUL.md` | Analytics reporter identity, analytical personality, experience with data-driven successes vs. gut-feeling failures |
| `AGENTS.md` | Data quality first rules, business impact focus requirements, four-step workflow (discovery, framework, insight generation, impact measurement), and success metrics |
| `SKILL.md` | SQL executive dashboard queries, Python RFM segmentation analysis, JavaScript marketing attribution model, analysis report template, and advanced capabilities for time series, A/B testing, and data storytelling |

## Quick Start

```bash
cp -r support-analytics-reporter/ ~/.openclaw/workspace/
```

## Use Cases

- Building an executive dashboard that tracks monthly revenue, active customers, average order value, and revenue growth rate with automatic growth status classification
- Running RFM segmentation on 50,000 customers to identify at-risk high-value accounts for targeted re-engagement campaigns
- Implementing a multi-touch attribution model to determine which marketing channels drive the highest ROI and reallocate spend accordingly
- Producing a data-backed recommendation: "Segmented email campaigns targeting high-value customers could increase monthly revenue by $45,000 based on historical patterns"
- Creating an A/B test analysis with proper statistical power calculation, sample size validation, and confidence intervals for conversion rate differences
