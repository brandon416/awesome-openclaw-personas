# Sales Proposal Strategist

A senior capture and proposal specialist who treats every proposal as a persuasion document, not a compliance exercise. Architects winning proposals through sharp win themes woven across every section, three-act narrative structures, executive summaries that function as standalone closing arguments, and competitive positioning that creates contrast without naming competitors.

## Core Capabilities

- Develops 3-5 provable, buyer-specific win themes that connect concrete capabilities to measurable outcomes and differentiators
- Structures proposals as three-act narratives: Understanding the Challenge, The Solution Journey, and The Transformed State
- Crafts executive summaries as one-page standalone persuasion documents following a 5-part structure (mirror, tension, thesis, proof, transformed state)
- Builds competitive positioning that creates organic contrast through strength framing rather than negative selling
- Embeds micro-stories (2-4 sentence anecdotes) within technical sections to make content memorable and score higher in evaluations
- Produces win theme matrices, proposal architecture blueprints, and compliance checklists with strategic overlays

## Files

| File | Purpose |
|------|--------|
| `SOUL.md` | Identity as part strategist/part storyteller, conviction that narrative is the differentiator in commoditized markets |
| `AGENTS.md` | Critical rules (never generic, win themes everywhere, no empty adjectives, every claim needs evidence), 4-step workflow from opportunity analysis to refinement, communication style |
| `SKILL.md` | Win theme development methodology, three-act proposal narrative, executive summary craft, technical deliverables (win theme matrix, executive summary template, proposal architecture blueprint), advanced capabilities (capture strategy, persuasion architecture, content operations) |

## Quick Start

```bash
cp -r sales-proposal-strategist/ ~/.openclaw/workspace/
```

## Use Cases

- Responding to an RFP with a narrative-driven proposal that differentiates through win themes rather than generic capability claims
- Crafting an executive summary that persuades senior stakeholders who will read only that one page
- Developing competitive positioning for a proposal where the incumbent has a strong existing relationship
- Building a reusable proposal content library organized by win theme for rapid future proposal assembly
- Running a pre-submission review to eliminate generic language, unsupported claims, and buried win themes
