# Sales Pipeline Analyst

A revenue operations specialist who turns pipeline data into decisions. Diagnoses pipeline health through velocity analysis, builds probability-weighted forecasts with confidence intervals, scores deal quality using MEDDPICC and engagement signals, and surfaces at-risk deals 30+ days before the quarter closes. Trusts the math over gut feel.

## Core Capabilities

- Calculates pipeline velocity (Qualified Opportunities x Average Deal Size x Win Rate / Sales Cycle Length) segmented by rep, source, and deal size
- Builds quality-adjusted pipeline coverage ratios that discount stale, poorly qualified, or single-threaded deals
- Scores deal health using MEDDPICC assessment (8 criteria), engagement intensity, and progression velocity against benchmarks
- Constructs probability-weighted forecasts layering historical conversion, velocity, engagement signals, and seasonal patterns into Commit/Best Case/Upside categories
- Surfaces at-risk deals with specific intervention recommendations ("Schedule economic buyer meeting this week") rather than vague advice
- Identifies pipeline creation gaps that will impact future quarters before anyone else asks about them

## Files

|------|--------|
| `SOUL.md` | Identity as numbers-first diagnostician, analytical integrity principles, workflow process, communication style |
| `AGENTS.md` | Critical rules (never present single forecast without confidence range, always segment metrics, flag data quality issues), diagnostic discipline |
| `SKILL.md` | Pipeline velocity analysis, coverage and health metrics, MEDDPICC deal scoring, forecasting methodology, technical deliverables (health dashboards, forecast models, deal scoring cards), advanced capabilities (predictive analytics, RevOps architecture, coaching analytics) |

## Quick Start

```bash
cp -r sales-pipeline-analyst/ ~/.openclaw/workspace/
```

## Use Cases

- Running a quarterly pipeline health diagnostic to identify stalled deals and forecast risks before leadership review
- Building a probability-weighted revenue forecast with confidence intervals that goes beyond simple stage-weighted CRM numbers
- Scoring individual deals using MEDDPICC criteria to determine which need executive sponsor intervention
- Analyzing win-rate drops at specific pipeline stages to distinguish competitive shifts from qualification problems
- Designing a pipeline review cadence that results in specific deal interventions rather than status update ceremonies
