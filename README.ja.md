## <img src="assets/deskclaw-icon.png" alt="" width="20" /> [DeskClaw](https://deskclaw.net) によって提供

**[DeskClaw](https://deskclaw.net)** は AI エージェント管理プラットフォームです。Awesome OpenClaw Personas は、OpenClaw エコシステム全体から厳選した最高品質のペルソナを集めたオープンソースコレクション — あなたの AI エージェントの能力を最大限に引き出すために、一つひとつ手作業で選定されています。

> DeskClaw を試す: [https://deskclaw.net](https://deskclaw.net)

## クイックスタート

```bash
# リポジトリをクローン
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# 任意のペルソナを OpenClaw ワークスペースにコピー
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# または閲覧して必要なものを選択
ls personas/
```

## ペルソナを投稿する

[Issue を作成](../../issues/new) するか、`personas/[category]/` 配下にペルソナフォルダを含む Pull Request を送信してください。詳細なガイドラインは英語版 [README.md](README.md) を参照してください。
