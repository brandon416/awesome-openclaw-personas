## <img src="assets/deskclaw-icon.png" alt="" width="20" /> Impulsado por [DeskClaw](https://deskclaw.net)

**[DeskClaw](https://deskclaw.net)** es una plataforma de gestión de agentes de IA. Awesome OpenClaw Personas es nuestra colección curada y de código abierto de las mejores personas de todo el ecosistema OpenClaw — seleccionadas a mano para ayudar a tu agente de IA a hacer más.

> Prueba DeskClaw: [https://deskclaw.net](https://deskclaw.net)

## Inicio rápido

```bash
# Clona el repositorio
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# Copia cualquier persona a tu workspace de OpenClaw
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# O explora y elige lo que necesites
ls personas/
```

## Enviar una persona

[Abre un issue](../../issues/new) o un Pull Request con tu carpeta de persona en `personas/[categoría]/`. Consulta el [README.md](README.md) en inglés para conocer las pautas completas.
