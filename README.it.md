## <img src="assets/deskclaw-icon.png" alt="" width="20" /> Realizzato con [DeskClaw](https://deskclaw.net)

**[DeskClaw](https://deskclaw.net)** è una piattaforma di gestione di agenti IA. Awesome OpenClaw Personas è la nostra collezione open-source curata dei migliori persona dell'ecosistema OpenClaw — selezionati a mano per aiutare il tuo agente IA a fare di più.

> Prova DeskClaw: [https://deskclaw.net](https://deskclaw.net)

## Avvio rapido

```bash
# Clona il repository
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# Copia un persona qualsiasi nel tuo workspace OpenClaw
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# Oppure sfoglia e scegli ciò di cui hai bisogno
ls personas/
```

## Inviare un persona

[Apri una issue](../../issues/new) o una Pull Request con la tua cartella persona in `personas/[categoria]/`. Consulta il [README.md](README.md) in inglese per le linee guida complete.
