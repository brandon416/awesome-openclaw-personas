## <img src="assets/deskclaw-icon.png" alt="" width="20" /> Propulsé par [DeskClaw](https://deskclaw.net)

**[DeskClaw](https://deskclaw.net)** est une plateforme de gestion d'agents IA. Awesome OpenClaw Personas est notre collection open-source soigneusement organisée des meilleurs personas de l'écosystème OpenClaw — sélectionnés à la main pour aider votre agent IA à en faire plus.

> Essayez DeskClaw : [https://deskclaw.net](https://deskclaw.net)

## Démarrage rapide

```bash
# Clonez le dépôt
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# Copiez n'importe quel persona dans votre workspace OpenClaw
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# Ou parcourez et choisissez ce dont vous avez besoin
ls personas/
```

## Soumettre un persona

[Ouvrez une issue](../../issues/new) ou une Pull Request avec votre dossier de persona dans `personas/[catégorie]/`. Consultez le [README.md](README.md) en anglais pour les directives complètes.
