**[DeskClaw](https://deskclaw.net)** ist eine KI-Agent-Management-Plattform. Awesome OpenClaw Personas ist unsere kuratierte, quelloffene Sammlung der besten Personas aus dem OpenClaw-Ökosystem — handverlesen, damit Ihr KI-Agent mehr leisten kann.

> DeskClaw ausprobieren: [https://deskclaw.net](https://deskclaw.net)

## Schnellstart

```bash
# Repository klonen
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# Beliebige Persona in Ihren OpenClaw-Workspace kopieren
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# Oder durchstöbern und auswählen
ls personas/
```
