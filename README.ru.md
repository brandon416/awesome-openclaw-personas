## <img src="assets/deskclaw-icon.png" alt="" width="20" /> При поддержке [DeskClaw](https://deskclaw.net)

**[DeskClaw](https://deskclaw.net)** — это платформа управления ИИ-агентами. Awesome OpenClaw Personas — наша курируемая открытая коллекция лучших персон со всей экосистемы OpenClaw, отобранных вручную, чтобы помочь вашему ИИ-агенту делать больше.

> Попробуйте DeskClaw: [https://deskclaw.net](https://deskclaw.net)

## Быстрый старт

```bash
# Клонируйте репозиторий
git clone https://github.com/TravisLeeeeee/awesome-openclaw-personas.git

# Скопируйте любую персону в ваш OpenClaw workspace
cp -r personas/ecommerce/e-commerce-product-scout/ ~/.openclaw/workspace/

# Или просмотрите и выберите нужное
ls personas/
```

## Отправить персону

[Откройте issue](../../issues/new) или Pull Request с папкой вашей персоны в `personas/[категория]/`. Полные рекомендации см. в английском [README.md](README.md).
